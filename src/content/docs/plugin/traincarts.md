#### 車両用タグ
呼び出せる車両は以下の通りです。

| 編成名 | 内容 | 識別用タグ |
| :--------- | ----------: | :----------: |
| M_LOCAL_5R | 普通列車 (5両)| local |
| M_SEMIEXP_5R | 準急列車 (5両) | semiexp |
| M_EXP_5R | 急行列車 (5両) | exp |
| M_RAPID_5R | 快速列車 (5両) | rapid |
| M_RAPIDEXP_5R | 快速急行列車 (5両) | rapidexp |
| M_LTDEXP_5R | 特急列車 (5両) | ltdexp |
